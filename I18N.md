# Localization guide

CaaS (ilia.ae fork) uses a minimal i18n system based on Java `ResourceBundle`
with a UTF-8 `Control` and a custom FreeMarker `TemplateMethodModelEx`.

## How it works

1. **`before` filter** in `WebLauncher` reads `Accept-Language` from each
   request, resolves to `Locale` (currently `en` or `ru`), stores it in a
   `ThreadLocal` via `I18n.setCurrent(locale)`.
2. **`I18nFreemarkerEngine`** wraps Spark's `FreeMarkerEngine` and injects
   `i18n` into the model of every render, pointing to `I18n.INSTANCE`.
3. In `.ftl` templates call `${i18n("key")}`. The instance is a
   `TemplateMethodModelEx`; FreeMarker invokes `.exec()` which loads the right
   bundle from `CURRENT_LOCALE` and returns the message.
4. **`after` filter** clears the thread-local so pooled Jetty threads don't
   leak locale state between requests.

Resource files:
- `caas-web/src/main/resources/i18n/messages_en.properties` — English (fallback)
- `caas-web/src/main/resources/i18n/messages_ru.properties` — Russian

## Adding a new key

1. Find the hardcoded string in a `.ftl` template, e.g.:
   ```html
   <h1>Check your server for compliance</h1>
   ```
2. Pick a dot-separated key (section.subsection.name):
   ```
   home.heading = Check your server for compliance
   ```
3. Add the key to **both** `messages_en.properties` and `messages_ru.properties`:
   ```
   # en
   home.heading=Check your server for compliance

   # ru
   home.heading=Проверьте сервер на соответствие стандартам
   ```
4. Replace in template:
   ```html
   <h1>${i18n("home.heading")}</h1>
   ```

## Parameterized messages

Use `MessageFormat` syntax (`{0}`, `{1}`, ...):

```properties
# en
server.added_confirmation=Added {0} to the list.
# ru
server.added_confirmation=Сервер {0} добавлен в список.
```

```html
${i18n("server.added_confirmation", server.domain)}
```

## Adding a new language

1. Create `messages_<lang>.properties` (e.g. `messages_de.properties`) in
   `caas-web/src/main/resources/i18n/`.
2. In `I18n.resolveFrom(Request)` add another branch for the language tag:
   ```java
   if (tag.startsWith("de")) { return Locale.GERMAN; }
   ```
3. Rebuild & deploy.

## Conventions

- **Keys are lowercase, dot-separated**, grouped by UI section:
  `home.*`, `about.*`, `server.*`, `test.*`, `footer.*`, `nav.*`,
  `form.*`, `validation.*`, `email.*`.
- **One line per key**, no blank lines within a section.
- **HTML entities allowed** (`&copy;`, `&amp;`) — rendered raw by FreeMarker.
- **Missing keys fall back to the key string itself** (see `I18n.exec()`) —
  handy for spotting untranslated spots in the UI.
- **Encoding is UTF-8** (not Java-escaped Unicode). Enforced by
  `UTF8_CONTROL` in `I18n.java`, don't rely on `native2ascii`.
